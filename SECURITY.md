# Security contact

Citadel Audit is proprietary software of GRY HAT CYBERSECURITY LLC.
This repository is the public download home. It does not contain the
application source.

Report a vulnerability in the app, a tester build, or this repository to:

**andy@gryhat.com**

Please include the operating system, the build you installed (the Release
name, if you have it), and what you observed. Give GRYHAT a chance to
look before any public write-up.

Do not include:

- A client's addresses, hostnames, or scan evidence
- A license key or Machine ID, unless Andy asks for the Machine ID in a
  private reply to confirm which install you mean
- Exploit payloads or a proof of concept written as something someone
  else could run against a third party

A GitHub issue is acceptable for a low-sensitivity product bug that
contains none of the above. Use the issue form. It is the wrong channel
for a vulnerability that names a client network or a bypass of the
license check.

Windows builds are an experimental, untested preview. A crash or a
refused scan on Windows is useful feedback. It is not, by itself, a
verified security boundary.
