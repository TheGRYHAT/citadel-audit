# Changelog

This file tracks the public download repository
[TheGRYHAT/citadel-audit](https://github.com/TheGRYHAT/citadel-audit).
It is not the changelog of the private application.

Application version discussed on the site is the shipped **2.0.0** line.
Per-build numbers belong on GitHub Releases when a binary is actually posted.
This repository does not publish binaries.
