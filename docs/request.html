Request a license key.

A Citadel Audit license is checked on the computer it was issued for. Tester builds ship without a key. This form does not store anything and does not open a GitHub issue. It prepares an email to andy@gryhat.com with the subject "Citadel Audit license request".

Where the Machine ID appears

  1. Install the tester build and open Citadel Audit.
  2. A build that does not yet have a license stops on the activation screen. That screen is where this computer's Machine ID is shown — the machine serial the key will be bound to.
  3. Copy that whole value into the field above. Do not send a screenshot of a client network in its place.
  4. If the app is already licensed when it opens, you do not need another key for that machine.

The activation check is local. There is no license server, and the request email is how a tester asks GRYHAT to sign a key for that serial.
